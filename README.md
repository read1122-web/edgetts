## 系統簡介

語音報讀系統個人版是一個專為學習障礙學生設計的 PDF 語音報讀工具，支援多種朗讀模式，並提供 PDF 標記功能，讓學生可以點選預先標記的範圍直接發音。

### 主要特色
- ✅ 支援本地 PDF 檔案和 Google 雲端硬碟檔案
- ✅ 多種朗讀模式：整頁朗讀、框選朗讀、觸控選取朗讀
- ✅ PDF 標記功能：手動標記、AI 自動標記
- ✅ 多種語音選擇：本機語音、Edge TTS 語音
- ✅ 可調整語速和音量
- ✅ 支援圖片辨識（需設定 API KEY）

## 快速開始

### 1. 載入 PDF 檔案

#### 方法一：載入本地檔案
1. 點選左上角的「選擇檔案」按鈕
2. 從電腦中選擇要載入的 PDF 檔案
3. 系統會自動載入並顯示第一頁

#### 方法二：載入 Google 雲端硬碟檔案
1. 在網址列輸入 Google 雲端硬碟檔案的分享連結
2. 系統會自動解析並載入檔案

**注意事項：**
- 雲端檔案必須設定為「知道連結的使用者」可檢視
- 標記功能僅限本地 PDF 檔案使用

### 2. 開始朗讀

載入 PDF 後，您可以使用以下方式進行朗讀：

- **整頁朗讀**：點選右下角的「整頁朗讀」按鈕
- **框選朗讀**：使用可移動的框選區域選擇要朗讀的內容
- **觸控選取**：勾選「觸控選取」後，用手指或滑鼠選取文字進行朗讀

## 主要功能

### 一、朗讀功能

#### 1. 整頁朗讀
- **位置**：右下角「整頁朗讀」按鈕
- **功能**：自動朗讀當前頁面的所有文字內容
- **操作**：
  1. 點選「整頁朗讀」按鈕
  2. 按鈕會變成「取消朗讀」，可隨時點選停止
  3. 系統會依序朗讀頁面中的每個句子

#### 2. 框選朗讀
- **位置**：頁面上的可移動框選區域
- **功能**：朗讀框選區域內的文字和圖片內容
- **操作**：
  1. 調整框選區域的位置和大小
  2. 點選框選區域內的「朗讀」按鈕
  3. 系統會朗讀框選區域內的所有內容（包含圖片辨識）

#### 3. 觸控選取朗讀
- **位置**：左側「觸控選取」勾選框
- **功能**：手動選取文字進行朗讀
- **操作**：
  1. 勾選「觸控選取」
  2. 使用手指或滑鼠拖曳選取要朗讀的文字
  3. 選取的文字會以紅色標示
  4. 點選右下角「朗讀選取文字」按鈕開始朗讀
  5. 點選「清除選取文字」可清除選取

### 二、PDF 標記功能

標記功能讓您可以預先在 PDF 上標記特定區域，之後點選標記區域即可直接發音。

#### 進入標記模式
1. 點選左上角「⚙️」設定按鈕
2. 在「三、PDF 標記功能」區塊中點選「標記區塊」
3. 系統會進入標記模式，游標會變成十字準星

**重要提醒：**
- 標記功能僅限本地 PDF 檔案使用
- 雲端檔案無法進行標記編輯
- 如需使用標記功能，請先下載 PDF 到本地，然後重新上傳

#### 手動標記
1. 進入標記模式後，點選工具欄的「手動標記」按鈕
2. 在 PDF 上拖曳滑鼠或手指，框選要標記的區域
3. 標記框會以藍色邊框顯示
4. 可以調整標記框的大小和位置

#### AI 標記（需設定 API KEY）
1. 進入標記模式後，點選工具欄的「AI標記」按鈕
2. 選擇「新增標記」或「重新標記」
3. 系統會自動分析 PDF 內容並標記可朗讀的區域
4. AI 標記會自動識別文字和圖片區域

#### 標記框操作
每個標記框都有以下功能按鈕（懸停在標記框上時顯示）：

- **🔒 鎖定/解鎖**：鎖定後無法移動、調整或刪除標記框
- **✏️ 編輯替換文字**：設定該標記區域的替換文字
- **🗑️ 刪除**：刪除該標記框

#### 保存和匯出標記
1. 標記完成後，點選「保存標記」將標記資料儲存到 PDF 檔案中
2. 點選「匯出PDF」下載包含標記的 PDF 檔案
3. 下次載入該 PDF 時，標記會自動恢復

#### 使用已標記的 PDF
1. 載入已標記的 PDF 檔案
2. 直接點選標記區域即可發音
3. 如果標記有設定替換文字，會使用替換文字進行朗讀

## QR Code 產生器

QR Code 產生器是一個輔助工具（檔案名稱：`voice-reader-qr.html`），可以快速生成語音報讀系統的專用網址和 QR Code，方便學生掃描後直接開啟報讀系統。

**檔案位置：** 請開啟 `voice-reader-qr.html` 檔案以使用 QR Code 產生器功能。

### 功能特色
- ✅ 快速生成報讀系統專用網址
- ✅ 自動生成 QR Code
- ✅ 支援 Google 試算表連結（破音字校正）
- ✅ 歷史紀錄管理（本地儲存）
- ✅ 批次匯入/匯出功能

### 使用前準備

#### 1. 檔案權限設定
**重要：** 使用 QR Code 產生器前，必須先設定檔案權限：
- **Google 試算表**（如有使用）：必須設定為「**知道連結的任何人皆可查看**」
- **報讀用 PDF 檔案**：必須設定為「**知道連結的任何人皆可查看**」

#### 2. 試算表格式規範（破音字校正）

如果您要使用破音字校正功能，需要建立一個 Google 試算表，格式如下：

| 序號 | 原始語詞 | 替換語詞 |
|------|---------|---------|
| 1    | 朝會    | 招會    |
| 2    | ...     | ...     |

**說明：**
- **A 欄（序號）**：標題行，可填寫序號
- **B 欄（原始語詞）**：標題行，填寫需要校正的原始語詞
- **C 欄（替換語詞）**：標題行，填寫替換後的語詞
- 第一行為標題行，從第二行開始填寫資料

### 操作步驟

#### 步驟 1：輸入檔案資訊

1. **檔案用途說明**（必填）
   - 輸入檔案描述，例如：「國語第一課」、「數學第三單元」等
   - 此說明會顯示在歷史紀錄中，方便日後辨識

2. **Google 試算表連結**（選填）
   - 如果不需要破音字校正，可留空
   - 如果需要破音字校正，請貼上 Google 試算表的完整連結
   - 格式：`https://docs.google.com/spreadsheets/d/...`

3. **報讀用 PDF 檔案連結**（必填）
   - 貼上 Google 雲端硬碟中 PDF 檔案的完整連結
   - 格式：`https://drive.google.com/file/d/...`

#### 步驟 2：生成 QR Code

1. 點選「生成並儲存」按鈕
2. 系統會自動：
   - 生成報讀系統專用網址
   - 生成 QR Code
   - 將資料儲存到歷史紀錄

#### 步驟 3：使用生成的 QR Code

生成成功後，您可以：

1. **複製網址**：點選「複製」按鈕複製報讀系統專用網址
2. **直接開啟**：點選「直接開啟」按鈕在新分頁中開啟報讀系統
3. **下載 QR Code**：在歷史紀錄中點選「下載 QR Code 圖片」按鈕
4. **列印 QR Code**：將 QR Code 圖片列印出來，供學生掃描使用

### 歷史紀錄管理

#### 查看歷史紀錄
- 所有生成的 QR Code 都會自動儲存在「歷史紀錄庫」中
- 歷史紀錄按建立時間排序（最新的在最上方）
- 點選說明文字可直接開啟該報讀系統網址

#### 單筆操作
每筆歷史紀錄提供以下操作：
- **查看 QR Code**：點選眼睛圖示查看 QR Code
- **下載 QR Code 圖片**：點選下載圖示下載單個 QR Code 圖片

#### 批次操作

1. **勾選多筆資料**
   - 勾選個別資料的核取方塊
   - 或勾選表頭的「全選」核取方塊選擇全部

2. **匯出勾選資料（ZIP）**
   - 勾選要匯出的資料
   - 點選「匯出勾選 (ZIP)」按鈕
   - 系統會生成一個 ZIP 檔案，包含：
     - `data_list.csv`：資料清單（CSV 格式）
     - `images/` 資料夾：所有勾選項目的 QR Code 圖片

3. **匯入資料（CSV）**
   - 點選「匯入 (CSV)」按鈕
   - 選擇之前匯出的 CSV 檔案
   - 系統會自動匯入所有資料到歷史紀錄

4. **刪除勾選資料**
   - 勾選要刪除的資料
   - 點選「刪除勾選」按鈕
   - 確認後會刪除選取的資料

### 注意事項

⚠️ **重要提醒：**
- 歷史紀錄僅儲存於瀏覽器中（使用 IndexedDB）
- 如果清除瀏覽器快取（Cache/Cookie），資料將會遺失
- **請定期使用「匯出」功能備份重要資料**

### 使用範例

#### 範例 1：基本使用（無破音字校正）
1. 檔案用途說明：`國語第一課`
2. Google 試算表連結：留空
3. PDF 檔案連結：`https://drive.google.com/file/d/1ABC123...`
4. 點選「生成並儲存」
5. 下載 QR Code 並列印給學生使用

#### 範例 2：使用破音字校正
1. 檔案用途說明：`國語第二課`
2. Google 試算表連結：`https://docs.google.com/spreadsheets/d/1XYZ789...`
3. PDF 檔案連結：`https://drive.google.com/file/d/1DEF456...`
4. 點選「生成並儲存」
5. 系統會自動使用試算表中的破音字校正規則

## 詳細操作說明

### 頁面操作

#### 翻頁
- **上一頁**：點選頂部的「上一頁」按鈕
- **下一頁**：點選頂部的「下一頁」按鈕
- **頁碼顯示**：頂部中央會顯示當前頁碼

### 語音設定

#### 選擇語音
- **位置**：右上角語音選擇下拉選單
- **選項**：
  - 本機語音（中文女聲）
  - 本機語音（英文女聲）
  - Edge TTS 語音（多種語音可選）

#### 調整語速
- **位置**：語音選擇下方的語速滑桿
- **範圍**：-50% 到 +50%
- **操作**：拖曳滑桿調整語速

#### 調整音量
- **位置**：語速滑桿下方的音量滑桿
- **範圍**：0% 到 100%
- **操作**：拖曳滑桿調整音量

### 標記框編輯

#### 移動標記框
1. 將滑鼠或手指放在標記框上
2. 按住並拖曳即可移動位置

#### 調整標記框大小
1. 將滑鼠移到標記框的四個角落或邊緣
2. 游標會變成調整大小圖示
3. 拖曳即可調整大小

#### 編輯替換文字
1. 懸停在標記框上，點選「✏️ 編輯」按鈕
2. 在彈出的視窗中：
   - 「原始文字」欄位：顯示標記區域的原始文字（點選可試聽）
   - 「替換文字」欄位：輸入要替換的文字（旁邊有「預覽」按鈕可試聽）
3. 點選「確定」儲存，或「取消」放棄修改

#### 鎖定標記框
1. 懸停在標記框上，點選「🔒 鎖定」按鈕
2. 鎖定後，標記框無法移動、調整或刪除
3. 再次點選可解鎖

## 進階設定

### API KEY 設定

API KEY 用於以下功能：
- AI 圖片辨識（框選朗讀時識別圖片內容）
- AI 標記功能（自動標記 PDF 可朗讀區域）

#### 取得 API KEY
1. 點選左上角「⚙️」設定按鈕
2. 在「一、API KEY 設定」區塊中點選「？」按鈕查看教學
3. 連線到 [Google AI Studio](https://aistudio.google.com/u/2/api-keys)
4. 登入 Google 帳號
5. 依照教學圖片建立並複製 API KEY

#### 設定 API KEY
1. 在「API KEY」輸入框中貼上您的 API KEY
2. 或使用「📷 掃描 QR Code」功能掃描 QR Code
3. 點選「儲存」按鈕
4. 系統會將 API KEY 儲存在瀏覽器中

#### 刪除 API KEY
- 點選「刪除 API KEY」按鈕即可清除已儲存的 API KEY

### PDF 快取管理

系統會自動將載入的 PDF 檔案快取到瀏覽器中，以加快下次載入速度。

#### 清除快取
1. 點選左上角「⚙️」設定按鈕
2. 在「二、PDF 快取」區塊中點選「清除 PDF 快取」
3. 系統會清除所有快取的 PDF 檔案

### 標記密碼保護

為了保護標記內容，系統支援設定密碼保護。

#### 設定密碼
1. 進入標記模式
2. 點選工具欄的「設定密碼」按鈕
3. 輸入密碼並確認
4. 之後進入標記模式時需要輸入密碼

#### 取消密碼保護
1. 進入標記模式（需輸入密碼）
2. 點選「設定密碼」按鈕
3. 在密碼輸入框中留空並確認
4. 即可取消密碼保護

## 常見問題

### Q1: 為什麼無法標記雲端 PDF 檔案？
**A:** 標記功能僅限本地 PDF 檔案使用。如需使用標記功能，請：
1. 下載雲端 PDF 檔案到本地
2. 使用「選擇檔案」功能上傳本地檔案
3. 即可進行標記操作

### Q2: 標記後如何保存？
**A:** 標記完成後，請依序執行：
1. 點選「保存標記」將標記資料儲存到 PDF
2. 點選「匯出PDF」下載包含標記的 PDF 檔案
3. 下次載入該 PDF 時，標記會自動恢復

### Q3: 為什麼 AI 標記功能無法使用？
**A:** AI 標記功能需要設定 Gemini API KEY。請：
1. 點選「⚙️」設定按鈕
2. 在「一、API KEY 設定」中設定您的 API KEY
3. 設定完成後即可使用 AI 標記功能

### Q4: 標記框無法移動或調整？
**A:** 請檢查標記框是否已鎖定：
1. 懸停在標記框上查看是否有鎖定圖示
2. 如果已鎖定，點選鎖定按鈕解鎖
3. 解鎖後即可移動和調整

### Q5: 如何清除所有標記？
**A:** 
1. 進入標記模式
2. 點選「清除標記」按鈕
3. 確認後會清除當前頁面的所有標記

### Q6: 標記框的工具欄按鈕看不到？
**A:** 
- 將滑鼠懸停在標記框上，工具欄會自動顯示
- 如果標記框太小，工具欄會顯示在框的上方

### Q7: 如何試聽替換文字？
**A:** 
1. 點選標記框的「✏️ 編輯」按鈕
2. 在「替換文字」欄位旁點選「預覽」按鈕
3. 系統會使用首頁設定的語音和語速進行試聽

### Q8: 支援哪些檔案格式？
**A:** 目前僅支援 PDF 格式。不支援圖片格式的 PDF（掃描檔），但可透過 AI 圖片辨識功能讀取圖片中的文字。

### Q9: QR Code 產生器在哪裡？
**A:** QR Code 產生器是一個獨立的工具頁面，檔案名稱是 `voice-reader-qr.html`。使用方式：
1. 開啟 `voice-reader-qr.html` 檔案
2. 輸入檔案資訊並生成 QR Code
3. 管理歷史紀錄和批次匯出

### Q10: 為什麼 QR Code 產生器無法讀取檔案？
**A:** 請確認：
1. Google 試算表和 PDF 檔案都已設定為「知道連結的任何人皆可查看」
2. 連結格式正確（包含完整的 Google Drive ID）
3. 檔案確實存在且可正常存取

### Q11: 如何備份 QR Code 產生器的歷史紀錄？
**A:** 
1. 勾選要備份的資料（或全選）
2. 點選「匯出勾選 (ZIP)」按鈕
3. 下載的 ZIP 檔案包含 CSV 資料清單和所有 QR Code 圖片
4. 之後可以使用「匯入 (CSV)」功能還原資料

### Q12: QR Code 產生器生成的網址如何使用？
**A:** 
- 生成的網址可以直接在瀏覽器中開啟
- 也可以將網址轉換成 QR Code 供學生掃描
- 掃描 QR Code 後會自動開啟報讀系統並載入對應的 PDF 檔案

### 鍵盤快捷鍵（如適用）
- 目前系統主要支援觸控和滑鼠操作

### 按鈕位置說明
- **左上角**：⚙️ 設定按鈕、選擇檔案按鈕
- **右上角**：語音選擇、語速/音量調整
- **頂部中央**：上一頁、頁碼、下一頁
- **右下角**：整頁朗讀、朗讀選取文字
- **左下角**：清除選取文字
- **左側**：觸控選取勾選框
- **底部工具欄**：標記模式下的操作按鈕
